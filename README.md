# Система управления закупками

Индивидуальный сквозной проект по дисциплине «Технологии разработки приложений на базе фреймворков».

## Назначение

Консольное приложение для учёта заявок на закупку, товаров, поставщиков и заказов. Проект является базовой версией, которая в следующих практических работах может быть расширена до веб-приложения.

## Целевая аудитория

Сотрудники организации, которые создают заявки на закупку, согласуют их и оформляют заказы поставщикам.

## Предметная область

Закупочная деятельность организации: формирование заявок, ведение справочника товаров и поставщиков, создание заказов на основании согласованных заявок и контроль состояния заказов.

## Основные сущности

- `Application` — заявка на закупку;
- `Product` — товар;
- `Supplier` — поставщик;
- `PurchaseOrder` — заказ поставщику.

## Основные функции

- просмотр товаров и поставщиков;
- просмотр заявок и расчёт их суммы;
- добавление товаров в заявку;
- согласование заявки при наличии товаров;
- создание заказа только на основании согласованной заявки;
- просмотр заказов и расчёт их суммы;
- отмена заказа на допустимом этапе;
- загрузка и сохранение данных в JSON.

## Объектная модель

В ПР3 основные сущности предметной области представлены классами. Объекты хранятся в коллекциях `list`, а связанные сущности содержат ссылки на соответствующие объекты:

- `Application.products` содержит объекты `Product`;
- `PurchaseOrder.application` содержит объект `Application`;
- `PurchaseOrder.supplier` содержит объект `Supplier`;
- `PurchaseOrder.products` содержит объекты `Product`.

Каждый основной класс имеет конструктор `__init__`, строковое представление `__str__`, методы предметной области и преобразование к/из данных JSON.

## Хранение данных

JSON используется как внешний формат хранения. В приложении используются объекты классов.

В JSON связанные сущности сохраняются по идентификаторам (`product_ids`, `application_id`, `supplier_id`), а при загрузке по этим идентификаторам восстанавливаются ссылки на объекты.

## Запуск

Создать виртуальное окружение и установить зависимости:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить программу:

```bash
python main.py
```
